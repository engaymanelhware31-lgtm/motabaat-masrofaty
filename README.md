# متابعة مصروفاتي

نسخة اختبار أولية لتطبيق ويب عربي RTL لإدارة الراتب والمصروفات.

## الملفات
- `index.html`: التطبيق والوظائف الأساسية.
- `manifest.json` و`sw.js`: إعدادات PWA والتشغيل كتطبيق ويب قابل للتثبيت.
- `icon-192.png`: أيقونة التطبيق.
- `preview-design.png`: صورة التصميم المرجعي المرفقة.

## تجربة محلية
افتح `index.html` في متصفح حديث. بعض ميزات PWA تحتاج إلى HTTPS أو خادم محلي، وقراءة الفواتير OCR تعتمد على مكتبة خارجية واتصال الإنترنت.

## اختبار تقرير الشهر
افتح تبويب «التقارير»، اختر الشهر المطلوب، ثم اضغط «طباعة تقرير الشهر / حفظ PDF». من نافذة الطباعة اختر الطابعة أو «Save as PDF».

## الدولة والعملة
من «الإعدادات والميزانية» اختر الدولة؛ تتغير العملة تلقائيًا ويمكن مراجعتها قبل حفظ الإعدادات.

## تنبيه
هذه نسخة تجريبية وليست منشورة على Google Play. البيانات محفوظة محليًا في المتصفح على الجهاز الحالي. اختبرها ببيانات تجريبية أولًا وصدّر نسخة احتياطية بانتظام. الصورة المرفقة تصور تصميمًا مقترحًا وليست لقطة فعلية للتطبيق أثناء التشغيل.

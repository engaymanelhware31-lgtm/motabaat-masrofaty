# متابعة مصروفاتي

تطبيق ويب تقدمي عربي لتسجيل الراتب والمصروفات وتحليلها، مع واجهة أولية لمسح الفواتير عبر OCR.

## التشغيل
- افتح `index.html` محليًا للمعاينة الأساسية.
- لتجربة تثبيت PWA وService Worker، انشر الملفات على HTTPS (مثل GitHub Pages).
- بيانات المصروفات تحفظ في `localStorage` على الجهاز والمتصفح الحالي.
- استخدم **تنزيل نسخة احتياطية JSON** بانتظام.

## مسح الفواتير
يعتمد OCR في هذه النسخة على Tesseract.js من CDN، ولذلك يحتاج اتصالًا بالإنترنت لتحميل المكتبة وبيانات اللغة عند أول استخدام. جودة استخراج الإجمالي تختلف حسب وضوح الصورة وتنسيق الفاتورة، ويجب مراجعة البيانات قبل الحفظ. إذا لم ينجح الاستخراج، يمكن إدخال الإجمالي يدويًا.

## حدود النسخة الأولى
- لا توجد مزامنة بين الأجهزة.
- لا يوجد ربط بنكي أو تسجيل دخول سحابي.
- الأرقام المستخرجة من OCR اقتراحات وليست بيانات موثقة تلقائيًا.
